# Security Policy

## Supported versions

During the beta phase, only the latest published version receives security fixes on a best-effort basis.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature under the repository Security tab, if enabled. Do not disclose credentials, exploit details or customer data in public issues.

## Operational safety

OpsAI may access remote infrastructure. Use least-privilege credentials and require explicit approval before any remediation actions. Never commit secrets, SSH private keys or production logs.
